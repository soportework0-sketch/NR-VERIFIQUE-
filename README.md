# 🛡️ NR VERIFIQUE

> Bot global de verificación y moderación para Discord.

NR VERIFIQUE es un bot diseñado para proteger servidores de Discord mediante un sistema de verificación configurable, moderación y diferentes herramientas administrativas.

---

## ✨ Características

### 🛡️ Sistema de verificación

NR VERIFIQUE permite configurar diferentes métodos:

- 🔢 Código MD
- 🤖 CAPTCHA
- 🧩 Puzle
- 📋 Cuestionario

El sistema permite configurar:

- 📍 Canal de verificación
- 👤 Rol verificado
- 📋 Canal de logs
- 🎨 Color del panel
- 🖼️ Imagen
- 💬 Mensaje personalizado

---

## 🌎 Idiomas

Actualmente NR VERIFIQUE incluye 6 idiomas:

- 🇪🇸 Español
- 🇺🇸 English
- 🇧🇷 Português
- 🇫🇷 Français
- 🇩🇪 Deutsch
- 🇮🇹 Italiano

Cuando el bot entra por primera vez a un servidor, solicita seleccionar el idioma.

Cada servidor puede tener su propio idioma.
